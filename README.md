# Minimal New Tab

Минималистичная страница новой вкладки для Microsoft Edge и Chrome. Расширение убирает визуальный шум стандартной вкладки, оставляя чистый фон и встроенный блокнот. Текст заметок автоматически сохраняется и восстанавливается при открытии новой вкладки. Цвет фона адаптируется к светлой или тёмной теме ОС.

## Возможности

- **Чистый фон** — никаких новостей, виджетов или обоев.
- **Встроенный блокнот** — пишите заметки прямо на новой вкладке.
- **Автосохранение** — текст сохраняется автоматически во время ввода.
- **Резервное копирование** — данные дублируются в `localStorage`, предотвращая потерю заметок при сбое или закрытии вкладки.
- **Синхронизация между вкладками** — открытые вкладки подхватывают изменения друг друга через `chrome.storage.onChanged`.
- **Ручное сохранение** — `Ctrl+S` / `Cmd+S`.
- **Контроль размера** — предупреждение при превышении лимита хранилища.
- **Адаптация к теме** — автоматическое переключение фона.
- **Доступность** — `prefers-reduced-motion`, `forced-colors`, видимое кольцо фокуса, отдельный `aria-live`-регион для статусов.
- **Проверка орфографии** — включена по умолчанию.
- **Конфиденциальность** — только разрешение `storage`. Расширение не собирает данные.

### Режим разработчика

1. Скачайте и распакуйте архив.
2. Откройте `edge://extensions/`.
3. Включите **режим разработчика**.
4. Нажмите **Загрузить распакованное** и выберите папку.

## Требования

- Microsoft Edge 149+ или Chrome 120+.
- Разрешение `storage`.

## Известные ограничения

- При одновременной активной печати в двух вкладках последняя сохранённая версия выигрывает. Idle-вкладка синхронизируется автоматически, а при конфликте показывается предупреждение.

## Журнал изменений

### 2.0.3

- Синхронизация между открытыми вкладками через `chrome.storage.onChanged`.
- Лимит размера берётся из `chrome.storage.local.QUOTA_BYTES`.
- Различаются ошибки квоты и прочие ошибки сохранения.
- Screen-reader-статус вынесен в отдельный `aria-live`-регион.
- `chrome.storage` используется через Promise API.
- Добавлен favicon и осмысленный `title` вкладки.

### 2.0.2

- Резервная копия не удаляется до успешной записи в `chrome.storage`.
- `Ctrl+S` работает на любой раскладке.
- Фокус ставится после загрузки заметок.
- При ошибке сохранения отложенная правка перезапускается с задержкой.
- Резервная копия дебаунсится при вводе.
- Проверка типа `result[STORAGE_KEY]`.
- `chrome.storage.local.set` обёрнут в `try/catch`.
- `body` использует `100dvh`.
- У `textarea` добавлен `aria-label`, у статуса — `role` и `aria-live`.

### 2.0.1

- Исправлена потеря правок, введённых во время сохранения (флаг `pendingSave`).
- Резервная копия перенесена из `sessionStorage` в `localStorage`.
- Исправлено восстановление полностью очищенного текста.
- `showStatus` корректно сбрасывает предыдущий таймер.

### 2.0.0

- Первый публичный релиз.
