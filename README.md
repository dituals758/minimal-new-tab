# Minimal New Tab

Минималистичная страница новой вкладки для Chromium-based браузеров. Расширение заменяет стандартную вкладку на чистую страницу со встроенным блокнотом и панелью закладок. Текст заметок автоматически сохраняется и восстанавливается при открытии новой вкладки. Панель закладок показывает только на кастомной вкладке, а не на всех.

## Возможности

- **Чистый фон** — никаких новостей, виджетов или обоев.
- **Встроенный блокнот** — пишите заметки прямо на новой вкладке.
- **Панель закладок** — отображает закладки из панели браузера только на кастомной новой вкладке. Поддержка папок с выпадающими меню.
- **Автосохранение** — текст сохраняется автоматически во время ввода.
- **Резервное копирование** — данные дублируются в sessionStorage, предотвращая потерю заметок.
- **Ручное сохранение** — `Ctrl+S` / `Cmd+S`.
- **Контроль размера** — предупреждение при превышении 4 МБ.
- **Адаптация к теме** — автоматическое переключение светлой/тёмной темы.
- **Стилизация под Chromium** — оформление повторяет нативный UI Chromium 152.
- **Доступность** — `prefers-reduced-motion`, `forced-colors`, видимое кольцо фокуса.
- **Проверка орфографии** — включена по умолчанию.
- **Конфиденциальность** — разрешения `storage` + `bookmarks`. Расширение не собирает данные.

## Установка

### Режим разработчика

1. Скачайте и распакуйте архив.
2. Откройте `chrome://extensions/` или `edge://extensions/`.
3. Включите **режим разработчика**.
4. Нажмите **Загрузить распакованное** и выберите папку.

## Требования

- Chromium 152+ (Chrome, Edge, Brave и др.)
- Разрешения: `storage`, `bookmarks`.
